The consumer-first API. Almost every test starts here, with `Timeline.Create()`, and stays on the
path through `Build()`, `SetupRun(...)` and `RunAsync()`.

If you are reading this before writing your first test, start with
[your first timeline](../learn/first-timeline.md) instead - it walks the same types in the order you
need them.
